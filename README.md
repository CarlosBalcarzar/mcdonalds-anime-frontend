# McDonald’s Anime · Frontend
Prototipo educativo en React 19 y Vite 6. Desde la raíz, con Node 22.12 o superior de la rama 22, ejecute npm ci. Copie .env.example a .env y ejecute npm run dev. Para producción ejecute npm run build. El resultado queda en dist.

En Vercel importe este repositorio, seleccione Vite y defina VITE_API_URL como la URL HTTPS de Render terminada en /api. Vuelva a compilar después de cambiarla. El frontend añade rutas como /products y /orders. El inicio de sesión por correo pasa por la API.
